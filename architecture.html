IVR — Complete Architecture

AI-Powered Voice IVR
LangGraph + Groq + Deepgram + ElevenLabs + Twilio  |  Version 1.0  |  June 2026

1. Overview

A production-grade voice IVR replacing a deterministic Amelia/BPM system with an LLM-powered LangGraph agent. Callers interact via phone (Twilio PSTN) or browser (WebRTC softphone). Audio is processed in real time: Deepgram for speech-to-text, ElevenLabs for text-to-speech, and the OpenAI Realtime API for PII-based identity authentication. Post-auth intent routing and all service flows run on Groq (llama-3.3-70b).

Core Capabilities

  • Multi-factor voice authentication (phone, DOB, name)
  • Policy info, loan, payment, beneficiary inquiries
  • PCI-compliant DTMF card / bank payment collection
  • GLBA privacy opt-out (verbatim script)
  • RAG-powered FAQ (pgvector knowledge base)
  • Live agent escalation / transfer

Compliance

  • PCI DSS — card data via DTMF only, never LLM
  • GLBA — verbatim privacy script, beneficiary restrictions
  • Max 3 auth attempts before escalation
  • Context lock during sensitive flows (payment)
  • Per-call session state, 1-hour TTL

5. Authentication State Machine

collecting_phone
    ├── found (party_search hit)
    │       └──► collecting_dob
    └── not found
            └──► confirming_phone
                    ├── yes ──► collecting_policy ──► collecting_dob
                    └── no  ──► collecting_phone (retry)

collecting_dob ──► confirming_dob
    ├── yes + auth match + 1 policy   ──► complete ✓  ──► acquire_access_token
    ├── yes + auth match + N policies ──► collecting_policy_selection ──► complete ✓
    ├── yes + no match                ──► collecting_name
    └── no                            ──► collecting_dob (retry)

collecting_name
    ├── match ──► complete ✓
    └── fail  ──► escalate  (max 3 total attempts)

On complete: acquire_access_token → all downstream API calls use Bearer token

6. DTMF Payment Flow (PCI)

payment_node sets otp_step = "collecting_card_dtmf" or "collecting_bank_dtmf"
        │
        ▼
STT is SUSPENDED — Deepgram transcripts ignored during DTMF collection
        │
Twilio event: "dtmf" ──► DTMFCollector.push_digit()
        │
        ├── CARD flow:  card_number (16d) → expiry (4d) → cvv (3-4d) → amount
        └── BANK flow:  routing_number (9d) → account_number → amount
                │
                ▼  on complete
        _on_dtmf_complete() ──► POST /payment/process (Bearer token)
                │
                ▼
        STT RESUMED — normal conversation continues
